## Codebase Patterns

- Use `argsIgnorePattern: '^_'` in ESLint for unused function parameters in Express middleware
- Tailwind 4.x uses `@import "tailwindcss"` and `@theme` block for custom colors
- ESLint config should have separate sections for frontend (src/) and backend (server/) with appropriate globals
- Use `concurrently` to run frontend and backend dev servers together
- better-sqlite3 uses WAL mode by default; add `*.db-shm` and `*.db-wal` to .gitignore
- Use `db.transaction()` for bulk inserts in better-sqlite3 for performance
- React Router v6+: Use `<Layout>` with `<Outlet />` for nested routes; `NavLink` for active styling
- Components organized as: `src/components/layout/` (Navbar, Footer, Layout), `src/components/ui/` (Spinner, Skeleton), `src/pages/`
- API routes organized in `server/routes/`: individual route files (e.g., reservations.js) mounted in index.js
- Validation middleware pattern: `server/middleware/validateX.js` exports middleware that validates req.body and calls next()
- Toast notification pattern: `src/components/ui/Toast.jsx` with auto-dismiss timer, success/error types
- Form validation pattern: mirror backend regex patterns on client-side for consistency
